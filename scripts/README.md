# Scripts

Repo tooling is grouped by domain. Keep new scripts inside the narrowest
matching folder instead of adding files directly under `scripts/`.

- `ai/`: AI memory tooling and any temporary cleanup helpers for extracted legacy assets.
- `benchmarks/`: JMH suite argument files and benchmark plotting helpers.
- `docs/`: documentation consistency checks.
- `quality/`: lint and static-quality helper scripts plus local baselines.
- `release/`: release and signing helper scripts.
- `tests/`: Python tests for the surviving script tooling.
